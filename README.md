# WallConnectorLog for iOS

**Work in progress — nothing to build or run here yet.**

A native iPhone companion to
[WallConnectorLog](https://github.com/mews-se/wallconnectorlog), maybe. The server already
does the around-the-clock logging; the idea is a phone-sized window into it, the way
[EVLog](https://github.com/mews-se/evlog-ios) is for TeslaMate: SwiftUI, talking only to a
server you run yourself, no account and no cloud.

Watch the repo if you want to know when that changes.
